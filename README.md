# Sorting Algorithms in Java

A small Java project containing implementations of several basic sorting algorithms.

## Algorithms

The project currently includes:

* Bubble Sort

## Tests

The sorting algorithms are tested using **JUnit** to verify their correctness with different input cases.

## Requirements

* Java 26
* JUnit 5.8

## Purpose

This repository is mainly intended for learning and practicing basic sorting algorithms and unit testing in Java.
